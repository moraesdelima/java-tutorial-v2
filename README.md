# Java Tutorial v2

## Propósito

Este tutorial é um material pedagógico completo para aprendizado da linguagem Java, com foco na versão **Java 21 LTS**. Todo o conteúdo — texto, exemplos de código e diagramas — é original, produzido especificamente para este material, e adequado para publicação em intranet corporativa.

O tutorial cobre desde os fundamentos da linguagem até os recursos mais recentes introduzidos entre Java 9 e Java 21, oferecendo uma trilha de aprendizado progressiva e autocontida.

## Público-Alvo

- Desenvolvedores com conhecimento básico de programação que desejam aprender Java
- Desenvolvedores Java que precisam se atualizar com as features modernas (Java 9–21)
- Equipes que buscam um material de referência interno em português

## Pré-Requisitos

- Conhecimento básico de lógica de programação (variáveis, condicionais, laços)
- Familiaridade com linha de comando (terminal)
- JDK 21 instalado no ambiente de desenvolvimento
- Editor de texto ou IDE de sua preferência (recomendado: IntelliJ IDEA, VS Code ou Eclipse)

## Como Utilizar

### Navegação Linear

Siga a ordem definida no arquivo [TOC.md](./TOC.md) para uma experiência de aprendizado progressiva. Cada tópico possui links de navegação (anterior/próximo) que permitem percorrer todo o material sequencialmente.

### Navegação por Tópico

Use o [Índice Principal](./index.md) para acessar seções específicas, ou o [TOC.md](./TOC.md) para localizar tópicos individuais.

### Glossário

Consulte o [Glossário](./glossario.md) para definições de termos técnicos utilizados ao longo do tutorial. Termos mantidos em inglês (como *Records*, *Sealed Classes*, *Virtual Threads*) possuem explicações em português no glossário.

### Exemplos de Código

Todos os exemplos de código são compiláveis com o JDK 21. Para executar um exemplo:

```bash
# Compilar
javac NomeDoArquivo.java

# Executar
java NomeDoArquivo
```

Exemplos marcados como fragmentos não são programas completos e servem apenas para ilustrar sintaxe ou conceitos isolados.

### Exercícios

Cada seção inclui exercícios práticos ao final. Recomenda-se resolvê-los antes de avançar para a próxima seção.

## Estrutura do Tutorial

O material está organizado nas seguintes seções:

1. **Conceitos de POO** — Fundamentos de orientação a objetos
2. **Fundamentos da Linguagem** — Variáveis, operadores, controle de fluxo
3. **Classes e Objetos** — Declaração, métodos, construtores, classes internas
4. **Anotações** — Uso e criação de anotações
5. **Interfaces e Herança** — Polimorfismo, classes abstratas, herança múltipla
6. **Números e Strings** — Tipos numéricos, caracteres, manipulação de texto
7. **Generics** — Tipos genéricos, wildcards, type erasure
8. **Pacotes** — Organização e modularização de código
9. **Tratamento de Exceções** — Try-catch, hierarquia de exceções, boas práticas
10. **Coleções** — Collections Framework, List, Set, Map, Queue
11. **Features Modernas (Java 9–21)** — Módulos, Records, Virtual Threads e mais

## Versão de Referência

**Java 21 LTS** (setembro de 2023) — Todos os exemplos e explicações utilizam esta versão como base.
