## Visão Geral

Esta seção apresenta os pilares fundamentais da Programação Orientada a Objetos (POO) no contexto da linguagem Java. Você aprenderá o que são objetos, classes, interfaces, herança e pacotes — os conceitos essenciais que sustentam toda a arquitetura de programas Java. Ao final, terá uma base sólida para compreender como o Java organiza e estrutura o código.
