# Java Tutorial v2 — Índice Principal

**Versão de referência: Java 21 LTS**

Este tutorial cobre a linguagem Java de forma completa e progressiva, desde os conceitos fundamentais de orientação a objetos até os recursos mais recentes introduzidos no Java 21. Todo o conteúdo é original e escrito em português (PT-BR).

---

## Seções

### [1. Conceitos de Programação Orientada a Objetos](./concepts/index.md)

Introdução aos pilares da orientação a objetos: objetos, classes, interfaces, herança e pacotes.

### [2. Fundamentos da Linguagem](./nutsandbolts/index.md)

Variáveis, tipos de dados, operadores, expressões, controle de fluxo, arrays e estruturas de repetição.

### [3. Classes e Objetos](./javaOO/index.md)

Declaração de classes, métodos, construtores, controle de acesso, classes internas, lambdas e referências de método.

### [4. Anotações](./annotations/index.md)

Conceitos básicos, anotações predefinidas e criação de anotações customizadas.

### [5. Interfaces e Herança](./IandI/index.md)

Definição de interfaces, métodos default, classes abstratas, polimorfismo, herança e composição.

### [6. Números e Strings](./data/index.md)

Tipos numéricos, caracteres, strings, autoboxing, buffers e conversões.

### [7. Generics](./generics/index.md)

Tipos genéricos, métodos genéricos, bounded types, wildcards, herança com generics e type erasure.

### [8. Pacotes](./package/index.md)

Criação, uso e organização de pacotes Java.

### [9. Tratamento de Exceções](./exceptions/index.md)

Conceitos de exceções, try-catch-finally, tipos de exceção, exceções customizadas, try-with-resources e boas práticas.

### [10. Coleções](./collections/index.md)

Visão geral da Collections Framework, List, Set, Map, Queue, iteração, ordenação e utilitários.

### [11. Features Modernas — Java 9 a 21](./modern/index.md)

Módulos, var, Text Blocks, Switch Expressions, Records, Pattern Matching, Sealed Classes, Virtual Threads, Sequenced Collections e melhorias na Stream API.
