## Visão Geral

Esta seção explora o sistema de anotações do Java — um mecanismo de metadados que permite adicionar informações ao código sem alterar seu comportamento direto. Você aprenderá a usar anotações predefinidas, entender como elas são processadas pelo compilador e pelo runtime, e criar suas próprias anotações customizadas.
