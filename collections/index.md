## Visão Geral

Esta seção apresenta a Collections Framework do Java — o conjunto de interfaces, implementações e algoritmos para armazenar, organizar e manipular grupos de objetos. Você aprenderá a utilizar listas, conjuntos, mapas e filas, além de dominar técnicas de iteração, ordenação e os utilitários disponíveis na classe Collections. A Collections Framework é uma das APIs mais utilizadas em qualquer aplicação Java.
