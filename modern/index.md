## Visão Geral

Esta seção reúne as principais funcionalidades introduzidas no Java desde a versão 9 até a 21 LTS. Cada tópico apresenta uma feature específica com explicação conceitual, exemplos práticos e comparações antes/depois que ilustram a evolução da linguagem. Os tópicos seguem ordem cronológica de introdução, permitindo acompanhar a evolução progressiva do Java moderno.
